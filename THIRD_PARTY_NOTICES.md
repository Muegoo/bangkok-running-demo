# Data and asset provenance

## OpenStreetMap

Map data © OpenStreetMap contributors. Data snapshots, derived GeoJSON and route geometry are identified as ODbL-1.0 in their metadata. Source references:

- https://www.openstreetmap.org/copyright
- https://www.openstreetmap.org/way/23483299 (Lumphini)
- https://www.openstreetmap.org/way/1306732424 (Benjakitti)
- https://www.openstreetmap.org/way/864170465 (Benjakitti Forest Park)

The selected Lumphini network was chosen visually using connected OSM pedestrian paths. It is not a Strava API dataset or a georeferenced GPS trace. The original personal screenshot is not distributed.

## Roblox assets

The selected place references an original Roblox Studio generated tree, documented in `roblox/assets/RainTree.json`. Other build variants in the source can use the additional metadata in `roblox/assets/`; these variants are not bundled as separate published places.

`CreatorParkTree.json` documents a model by Adrijan0830: https://create.roblox.com/store/asset/6020696518. This metadata is retained for the optional detailed-scene builder. Third-party hosted meshes and textures are not given a new license by this repository, and publication under another Roblox owner can require asset access.

Scene dressing is an artistic approximation. Google Street View imagery/textures are not embedded in the published place. Generated reference-based variants and extra imagery from the original local workspace are not included in this selected snapshot.
